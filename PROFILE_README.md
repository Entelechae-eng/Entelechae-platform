### ✦ The Creative Agent Ecosystem

Tools and sovereign runtimes built for AI coding agents (Claude Code, Cursor, Codex, and local models) to build world-class, anti-slop software:

```bash
# Add Entelechae agent capabilities to your coding workflow
npx skills add Entelechae-eng/skills
```

* **[Entelechae Visuals](https://entele-visuals.vercel.app/)** — *Giving coding agents taste.* An open-source generational library of 29,627+ creative resources, 897 React 19 motion primitives, and 683 WebGL shaders to stop generic AI template output.
* **[Entelechae Code](https://entelechae-code.vercel.app/)** — *The sovereign home for coding agents.* A distraction-free development environment with client-side SQLite persistence, multi-model reasoning, interactive live artifacts, and zero telemetry.
* **[Entele-motion](https://github.com/Entelechae-eng/Entele-motion)** — *Launch films straight from code.* Universal code-driven generative cinema, motion graphics, and audio synthesis for autonomous product demos.
* **[Entelechae Platform](https://github.com/Entelechae-eng/Entelechae-platform)** — *The sovereign computational substrate.* Native 120 FPS WebGPU canvas engine, high-density editorial interface, and local cryptographic vaults.
* **[Atelier Studio](https://github.com/Entelechae-eng)** — *Deterministic creative workspace.* Local-first spatial canvas with zero cloud lock-in.
